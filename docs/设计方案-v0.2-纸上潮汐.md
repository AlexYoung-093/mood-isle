# 心屿 v0.2 设计重构方案 —— 「纸上潮汐」

> 一句话：把心屿从"又一个 pastel 情绪 App"重做成**一本会呼吸的纸上手帖**——纸为底、墨为字、朱砂为印、潮为动。

---

## 1. 为什么重构：两类必须避开的趋同

**① 去"AI 味"。** AI 生成站点的指纹：蓝紫渐变、玻璃拟态卡片、135deg 线性渐变按钮、emoji 图标网格、无差别的圆角阴影。v0.1 虽用了珊瑚橙，但"白卡 + 阴影 + chip + emoji 网格"的骨架仍是典型 AI 模板，必须拆到骨头重做。

**② 去"同类味"。** 市售情绪 App（Daylio、MOODA、心岛日记、How We Feel）的设计语言高度趋同：马卡龙色、表情网格、打卡 streak、圆角卡片流。心屿若走同路，在面试场景里没有记忆点。

**参照系**（2025–2026 Awwwards / FWA 获奖站点共性）：编辑排版当家（typography carries the design）、暖中性底 + 单一强调色、颗粒肌理（grain）、2–4 个签名动效、其余克制。东方编辑排版（宋体、竖排、印章）在英文主导的获奖圈之外，是我们能独占的审美位。

## 2. 设计概念

产品名"心屿"自带意象：心里有座小岛，情绪是绕岛的海。v0.1 只用了名字，没用意象。v0.2 让意象成为交互本身：

- **海是活的**：页首一片生成式潮汐 Canvas，多层墨线缓慢呼吸，随一天时辰（晨 / 昼 / 暮 / 夜）改变光色，并响应手指 / 鼠标扰动。
- **记录是投石**：每次保存，海面落下涟漪——你的每条记录都真实改变这片海。
- **强度是浪高**：1–5 级强度改称「微澜 / 轻浪 / 涌浪 / 大浪 / 怒潮」，用海的词汇替代数字。
- **日历是潮汐表**：每月一张潮位图，有记录的日子绘一条迷你波浪（波高 = 强度、色 = 主导情绪），无记录处留白。
- **呼吸是望月**：呼吸练习是墨色夜空里一轮随节奏涨落的暖月。

## 3. 设计系统

### 3.1 材质
暖纸底 `#F5F0E8`，全站覆 3–4% 透明度 SVG 噪点颗粒（feTurbulence），制造印刷纸感，脱离"数字玻璃感"。

### 3.2 色彩（东方矿物颜料，全部降饱和、零渐变）
| 角色 | 色名 | 色值 | 用途 |
|------|------|------|------|
| 墨 | 玄墨 | `#26221C` | 正文、发丝线 |
| 灰墨 | 淡墨 | `#8C8478` | 次要文字 |
| 纸 | 暖纸 | `#F5F0E8` | 底色 |
| 强调 | 朱砂 | `#C04531` | 全站唯一强调色：交互态、印章、今日标记 |
| 积极 | 雌黄 | `#D9A441` | 情绪五色，语义专用 |
| 平静 | 松绿 | `#6E7F5C` | 同上 |
| 低落 | 黛蓝 | `#5B6B7C` | 同上（去紫、降饱和，绝不渐变） |
| 焦虑 | 赭石 | `#B26A38` | 同上 |
| 激烈 | 茜红 | `#9E3D34` | 同上 |

规则：强调色（朱砂）与情绪色（茜红）色相相近但分层使用——朱砂只属于 UI chrome，茜红只属于情绪语义。

### 3.3 字体
- 标题 / 情绪汉字 / 数字大字：宋体衬线栈（Songti SC / Noto Serif SC / serif）——书卷气；
- 正文 / 控件：系统无衬线（PingFang SC）——保证小字号可读；
- 日期 / 时间 / 编号：等宽数字（tabular-nums）——手帖的"账目感"；
- 装饰批注：竖排（writing-mode: vertical-rl）小字，东方编辑排版的签名元素。

### 3.4 布局
去卡片化：取消白卡 + 阴影堆叠，改用**发丝线（1px 低透明墨线）分隔 + 大留白 + 错位编辑网格**。移动优先 max-width 480px 不变，内部排版杂志化。区块以「其一 / 其二 / 其三」竖排小字编号，像手帖的章节。

## 4. 签名动效（4 个，其余克制）

1. **潮汐 Canvas**：requestAnimationFrame 多层正弦 + 噪声流线；晨昏光色；指针扰动；保存时落涟漪（ripple 环扩散 + 流线短暂泛起情绪色）。
2. **印章保存**：保存按钮是一枚朱印，按下盖印（scale + 印记加深），成功反馈为竖排朱印式 toast「已收入今日潮汐」。
3. **潮汐表日历**：日期格波浪线以 staggered draw-in 动画依次描画；点击日期，当日手帖页以墨晕 fade + 位移展开。
4. **望月呼吸**：全屏墨夜 + 暖月径向光晕 + 漂浮星尘，4-7-8 节奏月相涨落、文字渐隐渐现。

全部尊重 `prefers-reduced-motion`：开启后 Canvas 静态化、动效降级为淡入。

## 5. 交互组件重造（逐条对照 v0.1）

| v0.1（AI 模板件） | v0.2（纸上潮汐件） |
|---|---|
| 4 列 emoji 情绪网格 | 五行手风琴：大类 = 汉字 + 潮名 + 波浪线，展开内嵌纯文字标签，选中为墨底反白 |
| 原生 range 滑条 + emoji 脸 | 潮汐标尺：五座渐高波峰（SVG），点选 / 拖动，朱色标记 + 浪名 |
| pill chip 触发因素 | 发丝线框"批注签"，选中墨底白字 |
| 圆角白底输入框 | 手帖横线输入（仅底部发丝线） |
| 渐变胶囊按钮 | 朱印方章「落笔存屿」 |
| 白卡 + 左侧色条时间轴 | 日记页：大号衬线日期 + 发丝线分隔条目 + 情绪色细签 |
| 圆角色块日历格 | 潮汐表：浅墨数字 + 迷你波浪线，今日为朱砂圈 |
| emoji Tab 图标 | 汉字 Tab：「记」「溯」 |
| 白盒呼吸弹窗 | 全屏墨夜望月 |

## 6. 不变量（铁律）

- localStorage key `xinyu_entries` 与数据 schema 一字不动，老用户数据零损耗；
- 全部既有功能等价保留：记录（标签/强度/触发/备注）、今日列表、日历/时间轴、近 7 天占比、月份切换、删除、高强度负向情绪呼吸建议、自由呼吸入口、12356 热线；
- 单文件 `index.html`、零依赖、零构建的架构决策不变；
- 线上链接 https://mood-isle.app.workbuddy.host/ 不变，原地覆盖更新。
