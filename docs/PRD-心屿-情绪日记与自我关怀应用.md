# 心屿 · 情绪日记与自我关怀应用——产品需求文档（PRD）与开发方案

## 一、项目概述

### 1.1 背景与问题定义

年轻人在学业、职场、社交多重压力下情绪波动频繁，但日常情绪疏解面临三个断点：**记录门槛高**——多数日记类产品要求长文写作，用户坚持不下来；**记录之后没有下文**——只有存档没有反馈，用户感知不到记录的价值；**专业支持不可及**——心理咨询成本高、预约难，无法覆盖高频的轻度情绪波动。

本产品针对这三个断点做减法和加法：把记录压缩到 30 秒以内，把分析做成可视化的洞察反馈，把调节做成即点即用的自助方案，形成"记录 → 洞察 → 调节"的完整闭环。

### 1.2 产品定位

**产品名称**：心屿（Mood Isle）——寓意"心里有座小岛"，情绪起伏时随时靠岸。

**一句话定位**：面向年轻人（18-30 岁）的低门槛情绪记录与自我关怀在线应用，让每一次情绪波动都能被看见、被理解、被安放。

**价值主张拆解**：

| 用户痛点 | 心屿的解法 | 对应模块 |
|---------|-----------|---------|
| 记录麻烦，坚持不下来 | 30 秒三步记录：选情绪 → 拉强度 → 一句话备注 | 情绪记录 |
| 看不出情绪规律 | 日历色块 + 时间轴 + 触发因素统计 + 周期总结 | 情绪分析 |
| 情绪上来了不知道怎么办 | 按当前情绪即时推荐呼吸/冥想/音乐/运动方案 | 自助调节 |
| 担心隐私、怕被评判 | 无社交、免注册可记录、数据本地优先 | 用户体验 |

### 1.3 设计目标

1. 一次情绪记录完成时间 ≤ 30 秒，路径不超过 3 步。
2. 新用户首次打开到完成第一条记录 ≤ 1 分钟，无需注册。
3. 记录满 7 天后，分析页可产出第一份周总结，让用户尽快感知到"记录有用"。
4. 移动端为第一使用场景，桌面端同步适配。

## 二、目标用户与场景分析

### 2.1 用户画像

| 画像 | 特征 | 高频场景 | 核心诉求 |
|------|------|---------|---------|
| 大学生小雨（19-24 岁） | 考试周、论文、社交焦虑密集 | 考前失眠、寝室矛盾后想找人倾诉又犹豫 | 快速倾诉出口，看清自己情绪规律 |
| 职场新人阿哲（23-28 岁） | 加班多、通勤长、加班后情绪低频疲惫 | 深夜下班路上emo、周日晚焦虑 | 碎片时间自我调节，避免情绪积压 |
| 高压期人群林姐（25-30 岁） | 备考/求职/项目冲刺期，情绪波动大 | 连续高压后的崩溃时刻 | 低成本自救方法，追踪恢复过程 |

### 2.2 典型使用场景

**场景 A：深夜考后情绪低谷。** 小雨考砸了，睡前打开心屿，点击"难受"，强度拉到 4，备注"高数考砸了，感觉白学了"，触发因素勾选"考试"。系统识别到焦虑+低强度组合，即时弹出 3 分钟 4-7-8 呼吸练习引导。练完强度降到 2，应用记录这次改善值并鼓励一句。

**场景 B：周日晚焦虑。** 阿哲连续三周周日晚都感觉烦躁。第二周末他打开"洞察"页，看到触发因素 TOP1 是"工作/学业"，时段分布里周日晚 21-24 点是低谷区。周总结提醒他："连续 3 周，周日晚上是你最难熬的时段，试试提前安排一件小事犒劳自己。"

**场景 C：回顾恢复轨迹。** 林姐冲刺期结束后想看看自己最近状态，切到日历视图：一个月的情绪色块从橙色焦虑渐变为绿色平静，她收藏了"雨声白噪音"方案并标注"亲测有效"。

### 2.3 核心用户旅程

```
首次打开（免注册）→ 引导完成第一条记录 → 即时推荐一个调节方案 → 当晚回看时间轴
→ 第 7 天收到首份周总结 → 形成每日记录习惯 → 建立个人情绪档案
```

## 三、产品结构设计

### 3.1 信息架构

```
心屿
├── 记录（首页）
│   ├── 快速记录：情绪标签 → 强度评分 → 备注 → 触发因素
│   └── 今日情绪卡：当天已记录条目
├── 回顾
│   ├── 日历视图：月历情绪色块
│   └── 时间轴视图：连续记录流
├── 洞察
│   ├── 情绪统计：分布环形图 / 30天趋势线 / 触发因素TOP5 / 时段分布
│   └── 周期总结：周报 / 月报
├── 关怀
│   ├── 方案库：呼吸练习 / 冥想 / 音乐 / 运动 / 书写疗愈
│   ├── 收藏夹
│   └── 效果记录：练习前后强度对比
└── 我的
    ├── 记录天数 / 连续打卡
    ├── 隐私设置：数据导出 / 清除
    └── 求助资源：心理援助热线（常驻入口）
```

### 3.2 页面与导航

移动端采用底部 Tab 四栏导航：**记录、回顾、洞察、关怀**，"我的"折叠为右上角头像入口，降低首屏复杂度。桌面端转为左侧竖向导航，内容区自适应拉伸。

### 3.3 关键交互流程

**快速记录流（核心路径，目标 30 秒）**：首页点击大按钮"记一笔" → 九宫格情绪标签（5 大类 20 个标签，点选即高亮）→ 滑条选强度 1-5（带表情图标）→（可选）勾选触发因素 + 输一句话备注 → 保存。保存后立即询问："要不要舒缓一下？"引导进入调节方案。

**情绪低谷干预流**：当记录为高强度负面情绪（≥4）时，自动展开"现在就需要"快捷入口，跳过浏览直达呼吸练习页，减少情绪崩溃时刻的操作负担。

**效果反馈流**：进入任一调节方案时先记录一次当前强度，完成方案后再次记录，系统计算"情绪改善值"（前后差值）并累计到该方案的有效性统计。

## 四、功能设计详述

### 4.1 情绪记录模块

**情绪标签体系**：采用五色情绪分类，共 20 个标签，颜色作为全局视觉语言贯穿日历、图表。

| 大类 | 颜色 | 标签 |
|------|------|------|
| 积极 | 黄 | 开心、满足、兴奋、平静喜悦 |
| 平静 | 绿 | 平静、放松、专注、知足 |
| 低落 | 蓝 | 难过、失落、孤独、疲惫 |
| 焦虑 | 橙 | 焦虑、紧张、压力、迷茫 |
| 激烈 | 红 | 烦躁、愤怒、委屈、崩溃 |

**强度评分**：1-5 滑条，每档配表情图标与文字（1 轻微 / 3 明显 / 5 强烈），降低数字抽象感。

**触发因素标签**：预置 10 类——考试/学业、工作/加班、人际冲突、感情、家庭、健康、经济、天气、睡眠、其他。记录时可选多项，作为分析模块的核心输入。

**备注**：单行输入框， placeholder 提供示例（"一句话就好"），不做字数要求；预留语音转文字入口（移动端键盘自带）。

**回看视图**：

- **日历视图**：月历网格，每格底色为当日记录的情绪主色（多记录时取强度加权主色），强度用色块深浅表达，一眼看出整月情绪地貌；点击日期展开当日详情。
- **时间轴视图**：按时间倒序的连续卡片流，每条卡片 = 情绪图标 + 强度 + 标签 + 备注 + 时间，支持按情绪类别/触发因素筛选。

### 4.2 情绪分析模块

**统计看板（洞察页）**，四张图：

1. **情绪分布环形图**：统计周期内五类情绪占比。
2. **30 天趋势折线**：按日取记录强度均值，负面情绪用下方色带标注密集日。
3. **触发因素 TOP5 条形图**：各触发因素出现的频次与对应的平均情绪强度，同时回答"什么事出现最多"和"什么事对你影响最大"。
4. **时段分布热力条**：24 小时 × 情绪强度的分布，识别个人情绪低谷时段。

**触发因素识别规则**：显式标签统计为主（用户勾选的触发因素）；备注关键词匹配为辅（维护一张关键词词典，如"考/试"→考试、"加/班"→工作、"吵架/冷/闹掰"→人际冲突）。规则引擎起步，不依赖模型，保证离线可用与可解释性。

**周期性总结**：每周一推送上周周报、每月 1 日生成上月月报，内容包含——主导情绪与整体趋势（上升/下降/平稳）、最常出现的触发因素、一个具体可执行的关怀建议（如"本周周三情绪最低，试试周三午间安排 10 分钟散步"）。周报用规则模板生成温暖文案，预留 LLM 个性化总结接口作为迭代方向。

### 4.3 自助调节模块

**方案库结构**（V1 上线 5 类共 20+ 个方案）：

| 类别 | 内容示例 | 单次时长 |
|------|---------|---------|
| 呼吸练习 | 4-7-8 呼吸、箱式呼吸、碎片平复三步法 | 1-5 分钟 |
| 冥想引导 | 睡前身体扫描、专注力锚定、情绪命名练习 | 3-10 分钟 |
| 音乐 | 情绪歌单（平复/振奋/白噪音/自然声） | 自由 |
| 运动 | 办公室拉伸、5 分钟舒缓操、下楼走一圈引导 | 5-15 分钟 |
| 书写疗愈 | 引导式书写模板（"写给情绪的一封信"等） | 5-10 分钟 |

**情绪 → 方案推荐映射**：

| 当前状态 | 首推方案 | 备选 |
|---------|---------|------|
| 焦虑/紧张（橙） | 4-7-8 呼吸 | 冥想 · 身体扫描 |
| 低落/疲惫（蓝） | 音乐 · 平复歌单 | 书写疗愈 · 情绪命名 |
| 激烈/愤怒（红） | 运动 · 5 分钟舒缓操 | 碎片平复三步法 |
| 平静（绿/黄） | 冥想 · 专注力锚定 | 记录感恩时刻 |

**收藏与效果反馈**：每个方案右上角星标收藏，收藏夹支持自定义排序；每次使用自动记录前后强度差值，方案卡片展示累计"改善次数"与平均改善值，让用户沉淀"对我最有效的方法"。

### 4.4 用户体验设计

**视觉语言**：奶油白底色 + 珊瑚橙主色 + 大圆角卡片 + 手绘感插画，整体传递"温暖、不评判"的气质；情绪五色作为辅助色贯穿全站，形成一致的视觉记忆。文案风格口语化、低压力，禁止"你应该"式说教，多用"试试看""辛苦了"。

**低门槛设计原则**：

1. **免注册即用**：首次打开即可记录，数据存本地；需要云同步/多端使用时再引导注册。
2. **一键直达**：首页唯一大按钮"记一笔"，记录路径无任何弹窗与广告打断。
3. **无社交压力**：无点赞、无排行、无公开 feed，产品内所有数据默认仅本人可见。
4. **零要求不施压**：不设每日记录强制提醒，断签不惩罚；连续记录只做正向鼓励。

**隐私与安全设计**：

- 记录内容本地优先存储，云同步需显式授权；提供一键导出与一键清除。
- **心理健康边界**：产品不替代专业心理咨询。"我的"页与帮助页常驻心理援助热线（如全国 24 小时心理援助热线 12356）；当用户备注中出现自伤等高风险关键词时，立即展示求助资源卡片，并以温和方式提示寻求专业支持。

**移动端适配**：移动优先的响应式布局（CSS Flex/Grid + 断点适配）；操作目标 ≥ 44px 触控标准；滑条、九宫格等控件按拇指热区设计；支持深色模式跟随系统。

## 五、数据模型设计

核心数据实体（字段从简，仅为开发与部署铺路）：

| 实体 | 关键字段 | 说明 |
|------|---------|------|
| user | id、昵称、设备标识、created_at | 免注册即产生匿名档案 |
| mood_entry | id、user_id、emotion_tag、intensity、triggers[]、note、created_at | 情绪记录主表 |
| care_plan | id、category、title、content、duration、media_url | 方案库（可后台配置） |
| care_session | id、user_id、plan_id、intensity_before、intensity_after、created_at | 方案使用与效果记录 |
| favorite | id、user_id、plan_id、sort_order | 收藏夹 |
| weekly_report | id、user_id、period、summary_json、created_at | 周期总结缓存 |

## 六、技术方案

按"够用即可、快速上线"原则选型，技术细节不作为本 PRD 重点：

- **前端**：Vue 3 + Vite 单页应用，移动优先响应式；图表用 ECharts；PWA 支持，可"添加到主屏幕"获得类原生体验。
- **后端**：BaaS 托管方案（云数据库 + 云函数 + 静态托管），免运维、自带 HTTPS 与基础鉴权；匿名设备标识起步，注册登录为可选增强。
- **分析**：V1 纯规则引擎（标签统计 + 关键词词典），前端聚合计算 + 云端汇总；预留 LLM 总结接口。
- **部署**：静态资源托管 + 云函数 API，部署后输出公网 HTTPS 访问链接；CDN 加速移动端首屏。

## 七、开发计划与里程碑

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| M1 核心 loop | 快速记录 + 五色标签体系 + 日历/时间轴视图 | 可记录可回看的最小闭环 |
| M2 洞察 | 统计看板四张图 + 触发因素识别 + 周报 | 分析能力上线 |
| M3 关怀 | 方案库 20+ 方案 + 推荐映射 + 收藏与效果反馈 | 记录-调节闭环 |
| M4 打磨上线 | 视觉走查、移动端适配验收、隐私与求助资源接入、部署 | 公网可访问链接 |

里程碑串行推进，M1 完成即可部署内测链接，后续每阶段增量更新到同一链接，保证"始终可在线访问"。

## 八、成功指标与迭代方向

**北极星指标**：周活跃记录用户数（每周完成 ≥ 3 次记录的用户）。

**辅助指标**：首次会话完成记录率（目标 ≥ 60%）、记录 30 秒达成率、方案使用率（记录后进入调节的比例）、平均情绪改善值、次日/7 日留存。

**迭代方向（V2+）**：LLM 个性化月度情绪画像；情绪与生理数据（睡眠/步数）关联分析；可选匿名"树洞"轻社区；校园/企业场景合作版。

## 九、风险与应对

| 风险 | 应对 |
|------|------|
| 用户把产品当心理咨询替代品 | 全程明示边界：常驻求助热线入口，高风险关键词触发专业资源提示 |
| 隐私泄露担忧 | 本地优先存储、最小化收集、显式授权云同步、一键清除 |
| 记录难以坚持 | 无惩罚机制 + 周总结价值反馈 + 30 秒低门槛，靠价值感而非打卡压力驱动留存 |
| 自助方案效果不彰 | 效果反馈数据驱动方案库优胜劣汰，持续补充高改善值方案 |

---

**文档说明**：本 PRD 为 V1 范围定义，覆盖题目要求的四项能力（情绪记录、情绪分析、自助调节、移动端体验）与在线部署交付路径。M1 启动后按里程碑推进，产品结构与功能设计以此为准。
