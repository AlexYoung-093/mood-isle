# 心屿 v0.3 设计方案 —— 「观澜」

> 一句话：让记录有回声。v0.2 解决"美而不趋同"，v0.3 解决"记了之后得到什么"——基于真实用户痛点的差异化功能包。

---

## 1. 调研依据：情绪类产品用户的五个真实痛点

| # | 痛点（来源） | 代表性证据 | v0.3 对策 |
|---|---|---|---|
| P1 | **数据 ≠ 洞察** | Daylio 五年半用户："漂亮的图表，零 actionable wisdom"；图表显示周日情绪低，却无法说为什么 | 潮信周结：自然语言叙事复盘，不写判断、只讲贴近记录的事实 |
| P2 | **打卡焦虑** | 应用商店差评 35% 提及断签挫败；62% 焦虑用户称 streak 让其更焦虑；"断签一天，愧疚到卸载" | 反 streak 设计：本周岸线只呈现不惩罚，缺席不标红，文案"海不催人" |
| P3 | **情绪不是单色** | How We Feel 用户持续要求 mixed/neutral 状态；单词标签装不下真实感受 | 相伴情绪：每条记录可择主 + 伴两个情绪（权重 1 : 0.5） |
| P4 | **数据带不走** | Daylio 换机丢记录为长期差评点 | 一键导出手帖（Markdown）+ JSON 全量备份，数据主权在用户 |
| P5 | **练了不知道有没有用 / 找不到旧记录** | 自助调节无效果反馈闭环；诱因相关记录无法检索 | 呼吸练前练后浪级对比（调匀档案）；时间轴全文搜索 |

趋势佐证：2026 年 UX 基线——深色模式是"成对设计令牌"而非反色（Dark Mode 2.0）；数据可视化转向"数据叙事"（data storytelling，图表要说话）；微交互须有功能目的、150–600ms、cubic-bezier、尊重 reduced-motion。v0.3 全部遵循。

## 2. 三条产品理念（差异化宣言）

1. **海不催人**：无 streak、无提醒、无推送。记录页只有"本周岸线"——七个圆点呈现本周哪几天来过，缺席的日子只是留白，不标红、不计数断裂。
2. **数据是回声，不是报表**：分析页不叫"统计"，叫「观澜」；最重要的位置不给图表，给一封「潮信」——用散文把这一周讲回给用户听。
3. **情绪不是单色**：允许"难过 × 疲惫"共存。主情绪为浪，相伴为涌，日历取色按 1 : 0.5 加权。

## 3. 功能规格

### F1 观澜页（新第三 Tab「观」，对应 PRD M2）
- **潮信（周结）**：模板化叙事生成，覆盖：本周笔数与主导水域、第一诱因、浪最高的一天、时辰倾向（"潮水似乎总在夜深时涨"）、与上周笔数环比。稀疏数据（<3 笔）降级为勉励文案，明确"笔少不代表海浅"。
- **30 日潮位曲线**：手卷 SVG 曲线（Catmull-Rom 平滑），纵轴浪级一至五（微澜—怒潮），有记录日设色点（当日主导情绪色），断日留白；入场时曲线描画动画。
- **水域构成**：五色横条 + 衬线数字 + 占比。
- **诱因榜 TOP5**：名次 + 诱因 + 笔数 + 横条。
- **时辰分布**：晨/昼/暮/夜四柱，柱高 = 笔数。
- **调匀档案**：呼吸练习次数 + 有对比记录的平均潮退级数。

### F2 相伴情绪（对应 P3）
手风琴标签允许择二：首择为主（墨底反白 + 朱砂点），再择为伴（墨底反白 + 空心点）；第三次点选提示"最多两味"。数据 schema 增量字段 `cat2`/`tag2`，旧数据零影响。日历当日主色按 主1.0/伴0.5 加权。

### F3 夜航模式（对应趋势 Dark Mode 2.0）
完整暗色设计令牌（`body.night` 覆盖全部 CSS 变量：墨纸 #1B1812、暖墨字 #E8E0D4、颜料色提亮 10–15% 保对比度），非反色；全站 0.6s 色彩过渡；潮汐 Canvas 双色版（昼墨线/夜暖线）；页首「夜航 / 晓行」开关，`localStorage` 持久化。呼吸浮层本来即是夜色，天然一致。

### F4 时间轴搜索（对应 P5）
手帖页顶部横线搜索框：实时匹配备注 / 情绪标签 / 大类名 / 诱因，结果按日分组渲染不变。

### F5 导出手帖（对应 P4）
观澜页底部两枚发丝线按钮：「导出手帖 .md」生成排版精良的手帖文本（按日分组、含相伴情绪与浪级）；「备份 .json」全量导出 entries + breath_log。Blob 本地下载，无服务器。

### F6 呼吸效果反馈（对应 P5，PRD M3 效果反馈）
望月呼吸完成 4 轮后，浮层底部浮现"此刻的浪？"——五级浪词点选；若本次练习由高强度建议卡进入，自动带入练前浪级，展示"怒潮 → 涌浪，潮退两级"。写入 `xinyu_breath_log`（新 key，additive）。

### F7 本周岸线 + 翻月动效
- 记录页「今日」节内：一至日七个点位，有记录日填当日主导情绪色，今日朱砂圈；无计数、无连续天数。
- 回顾页翻月：日历整体按方向滑出滑入（300ms cubic-bezier）；观澜页各区块滚动浮现 + 曲线描画。

## 4. 不变量（铁律）

- `xinyu_entries` 既有字段语义不变，`cat2/tag2` 为可选增量；旧数据读写无损。
- 新增 `xinyu_breath_log`、`xinyu_night` 均为 additive key，互不影响。
- v0.2 全部功能与视觉语言保留；单文件零依赖架构不变。
- 线上链接 https://mood-isle.app.workbuddy.host/ 原地更新不变。

## 5. 验收口径

观澜五区块 + 潮信在≥4 条测试数据下渲染正确；相伴情绪贯穿保存/今日/潮汐表/手帖/导出；夜航全站无残色且 Canvas 换色；搜索实时过滤；导出文件内容完整；呼吸反馈写入与调匀统计正确；reduced-motion 下全部动效降级；console 零报错。
